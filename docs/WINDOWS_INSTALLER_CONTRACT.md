# عقد مثبتات منظومة باء على Windows

## نطاق العقد

يغطي هذا العقد مثبتات نظم وباء وتكوين وقلم والمثبت الشامل «عدة تطوير باء».
لا يغيّر عقد حزم مشاريع تكوين ولا مخزن SDK المستقبلي؛ تلك طبقات مستقلة.

## هوية المنتجات

- لكل منتج `AppId` ثابت لا يتغير بين الإصدارات.
- الاسم الناتج هو `<product>-setup-<version>-x64.exe`.
- المثبت الافتراضي لكل المستخدمين، ويستخدم `{autopf}` ويطلب الرفع مرة واحدة.
- يدعم كل مثبت مستقل `/CURRENTUSER` من سطر الأوامر عند الحاجة.
- كل مكوّن يملك ملفاته وقيد الإزالة ومتغيرات البيئة الخاصة به فقط.

## PATH

- يضيف نظم مجلد `bin` الذي يحوي `نظم.exe` و`nazm.exe`.
- يضيف باء المجلد الذي يحوي `baa.exe` فقط.
- يضيف تكوين مجلد `bin` الذي يحوي `تكوين.exe` و`takween.exe`.
- لا يضيف قلم ولا Baa-LSP أي مجلد إلى `PATH`.
- لا يضاف رابط باء الخاص أو DLLs الخاصة به إلى `PATH`.
- التطبيع غير حساس لحالة الأحرف والشرطة المائلة والاقتباس والشرطة النهائية.
- الترقية لا تنشئ قيدًا مكررًا، والإزالة تحذف القيد المطابق فقط.

## الاعتماديات والملكية

- نظم مستقل ولا يعتمد على وقت تشغيل خارجي.
- باء يكتشف الأمر العربي `نظم` من `PATH`، ويملك رابط Windows الخاص به.
- تكوين يكتشف باء ونظم من `PATH` ولا ينسخهما.
- قلم يضم Baa-LSP داخليًا، ويكتشف باء وتكوين ونظم ولا ينسخها.
- يسجل بيان العدة Baa-LSP كبرنامج كامل مملوك لقلم، مع إصداره ومسار فحصه؛
  لا يمنحه مثبتًا أو قيد إزالة ثانيًا لأن ذلك سيكسر ملكية ملفات قلم.
- غياب اعتمادية لا يمنع تثبيت المكوّن المستقل؛ يسجل فحص الصحة الحالة بوضوح.

## التشغيل الصامت

العقد الموحد للمثبتات الفرعية هو:

```text
/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP- /ALLUSERS
```

لا يعرض المثبت الصامت حوارات تحذير. تعاد الأخطاء عبر كود الخروج والسجل.

## المثبت الشامل

- يحمل المثبتات الأربعة داخله ولا ينزل ملفات أثناء التثبيت.
- تشمل هذه المثبتات البرامج الخمسة: نظم وباء وتكوين وقلم وBaa-LSP الداخلي.
- يتحقق من SHA-256 قبل تشغيل أي مثبت.
- يشغّلها بالتتابع: نظم ثم باء ثم تكوين ثم قلم.
- لا يشغل المثبتات بالتوازي ولا يعيد كتابة ملكية ملفاتها.
- يحتفظ بسجل منفصل لكل مكوّن ويذكر أول مكوّن فاشل وكود خروجه.
- لا يزيل إصدارًا صالحًا سبق للمستخدم تثبيته عند فشل مكوّن لاحق.

## بوابة الإصدار

لا ينشر إصدار عام قبل اجتياز التثبيت والترقية والإصلاح والإزالة على Windows
نظيف، والتحقق من المسارات العربية والمسافات والمسارات الطويلة، وفحص أوامر
`نظم` و`baa` و`تكوين` من جلسة طرفية جديدة، وتشغيل قلم من قائمة ابدأ.
