# قائمة تحقق إصدار عدة تطوير باء

## سلامة المدخلات

- [ ] المثبتات الأربعة تحمل أسماء الإصدارات المحددة في عقد الإصدار.
- [ ] لكل مثبت مستقل ملف `.sha256` مطابق.
- [ ] ملف `eco-installer-manifest-v1.json` يثبت الأسماء والإصدارات والهضم والترتيب.
- [ ] كل مثبت مستقل موقّع بتوقيع Authenticode صالح لإصدار عام.
- [ ] المثبت الشامل موقّع بالتوقيع نفسه أو بتوقيع إصدار موثوق آخر.

## دورة الحياة

- [ ] تثبيت صامت لكل المستخدمين على Windows 10 نظيف.
- [ ] تثبيت صامت للمستخدم الحالي بلا صلاحيات إدارية.
- [ ] إعادة تشغيل المثبت نفسه للإصلاح دون تكرار `PATH`.
- [ ] الترقية من آخر إصدار منشور.
- [ ] إزالة قلم ثم تكوين ثم باء ثم نظم دون حذف إدخالات لا تملكها المنظومة.
- [ ] تثبيت وإصلاح وإزالة في مسار عربي يحوي مسافات ومسارًا طويلًا.

## فحص التشغيل

- [ ] يعمل `نظم --إصدار` و`nazm --version` في جلسة طرفية جديدة.
- [ ] يعمل `baa --version` ويستخدم نظم من `PATH` والرابط الخاص من تثبيت باء.
- [ ] يعمل `تكوين --إصدار` و`takween --version` ويبنيان مشروع باء.
- [ ] يبدأ قلم، ويبدأ Baa-LSP الداخلي، وتظهر إعدادات اكتشاف الأدوات الخارجية.
- [ ] يحرر قلم ملف `.نظم` ويجمعه ويبني مشروع نظم.
- [ ] يحتفظ المثبت الشامل بالبيان وسجل مستقل لكل مكوّن.

## مخرجات الإصدار

- [ ] ناتج المثبت الشامل هو `baa-developer-kit-setup-<version>-x64.exe`.
- [ ] ملف SHA-256 المنشور يطابق المثبت المنشور بالبايت.
- [ ] اجتازت أعمال CI لكل من نظم وباء وتكوين وقلم وعدة التطوير الالتزام نفسه.
- [ ] سُجل رقم Windows والبنية ونتيجة الفحص في ملاحظات الإصدار.

لا يجوز وضع علامة إصدار عام عند بقاء بند مطلوب غير متحقق. يمكن أن تبقى
النسخ المحلية ونسخ CI غير موقعة، لكن يجب وصفها بوضوح على أنها لمرحلة الاختبار.
